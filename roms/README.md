# Cartuchos

Coloca aquí archivos `.gb` y `.gbc` que tengas permiso de distribuir. Se permiten subcarpetas. No incluyas ZIPs.

GitHub Actions genera `catalog.json` automáticamente al publicar. Para probar en XAMPP después de añadir juegos, ejecuta `npm run build` en la raíz del repositorio.

Personaliza nombres e identificadores en `config.json`. No es necesario editar el HTML. Consulta el README principal.
